# 냥빌 (YangVil)

털실 바구니에서 태어난 고양이를 키우고, 파티를 꾸려 골목길 모험을 떠나는 육성 수집 RPG.

## ▶ 바로 플레이: https://yangvil.deuklab.workers.dev

- 설치 없이 브라우저(크롬·엣지 권장)에서 바로 실행
- main에 푸시하면 자동 빌드·배포 → 항상 최신 버전
- 플랫폼: PC(Windows) · 웹 브라우저(WebGL)
- 엔진: Unity 6000.6.8f1 (정본: ProjectSettings/ProjectVersion.txt)

## 지금 버전 (YangVillage 이식판)
- 시작 씬 = `Assets/Scenes/YangVillage.unity` (빌드 0번)
- Godot 프로젝트 `YangVillage/game` 의 현재 화면·규칙을 그대로 옮김
- 흐름: 인트로 → 마을(마당·부화소·상점·식구) → 모험 지도 → 전투 → 결과 → 마을
- 코드: `Assets/Scripts/YangVillage/` (Core = 규칙, Ui = 화면)
- 저장: `persistentDataPath/yangvillage_save.json`
- 아래 "이전 버전" 이하 = `Assets/Scenes/Intro.unity` 설명. 그 씬을 직접 열어 Play 하면 이전 버전 실행

## 에셋 바꾸기 (협업자용)
- 코드 수정 없음 → 그림 파일 교체 또는 표(TSV) 한 줄 수정
- 그림 폴더 `R` = `Assets/Resources/YangVillage/assets/shared`
- 표 폴더 `T` = `Assets/Resources/YangVillage/Tables` (TSV, 확장자 .txt)

### 그림이 있는 곳
| 종류 | 파일 |
|---|---|
| 고양이 16종 (4무늬×4직업) | `R/cats/cat_professions.png` (4×4 칸) |
| 적 (쥐·비둘기·보스) | `R/actors/*.png` |
| 타격·필살·발사 이펙트 | `R/effects/*.png` |
| 속성 아이콘 6종 | `R/effects/elements.png` (4×6 칸) |
| 마당·전투 배경 | `R/world/village_courtyard.png` |
| 마당 소품 | `R/props/*.png` |
| 지도 노드·코인 | `R/ui/*.png` |
| 메뉴 바구니·깃발 | `assets/ui/village/*.png` |

- 베기 궤적·불티·컷인 띠·땀·별 = 그림 없이 도형으로 그림. 색 = `T/element.txt` 의 `color`

### 1) 같은 자리 그림만 바꾸기 (가장 쉬움)
- png 를 같은 이름·같은 칸 배치로 덮어쓰기 → Unity 로 돌아오면 자동 반영
- 여러 칸 시트는 칸 수 유지. 크기 자유 (칸 = 가로÷열, 세로÷행)
- 배경 투명 PNG

### 2) 새 그림 추가해서 바꿔 끼우기
- png 를 `Assets/Resources/YangVillage/assets/` 아래에 넣기
- `T/sprite.txt` 에 한 줄 추가: `sprite_id  path  columns  rows  start  count`
- `path` = `res://assets/...png` (Resources/YangVillage 기준)
- 한 장짜리 = `1 1 0 1`. `count` 2 이상 = 칸 넘기는 애니메이션 (0.15초)
- 쓸 곳의 표 칸에 새 `sprite_id` 적기

| 바꿀 것 | 표 · 칸 |
|---|---|
| 고양이 한 마리 외형 | `cat.txt` → `sprite_id` |
| 적 한 종 외형 | `enemy.txt` → `sprite_id` (빈칸 = 지역 공용) |
| 지역 공용 적·보스 | `region.txt` → `sprite_id`, `boss_sprite_id` |
| 속성 타격·필살 이펙트 | `element.txt` → `hit_sprite_id`, `skill_sprite_id` |
| 속성 발사체·아이콘 | `element.txt` → `shot_sprite_id`, `sprite_id` |
| 전투 배경 | `config.txt` → `battle_backdrop_sprite_id` |
| 돌진 먼지 | `config.txt` → `dust_sprite_id` |

### 3) UI 색·글자·타격감
- 색: `Assets/Scripts/YangVillage/Ui/Kit.cs` 맨 위 색 목록 (Ink·Paper·Accent·Grass…)
- 문구: `T/text.txt` 의 `ko` 칸
- 폰트: `Assets/Art/UI/Fonts/Galmuri11 SDF.asset` (씬 `Boot` 오브젝트 font 칸)
- 히트스톱·흔들림·넉백·확대·컷인 시간: `T/config.txt` (`*_ms`, `*_px`, `*_pct`)

### 4) Godot 원본과 맞추기
- 정본 = Godot `YangVillage/game` (표·그림)
- Godot 쪽 수정 후: `python scripts/sync_godot_village.py` → 표·그림 다시 복사
- Unity 에서만 고친 표·그림은 이 명령에 덮어써짐 → Godot 에도 같이 반영

```

```

## 타격감 조절값
- 위치: presentation.feel → 히트스톱·화면 흔들림·넉백 거리·돌진 비율·컷인 시간
- 이펙트·효과음 슬롯과 같이 조절하면 타격감이 바뀜

## 시작하기
- 인트로에서 `시작하기` → 마을로 이동
- 첫 고양이 `치즈`(불꽃)는 모닥불 집에 살고 파티에 들어가 있음
- 30초 뒤 부화하는 삼색이 바구니 1개, 우유 2개, 츄르 3개 지급
- `처음부터`는 저장을 지우고 새로 시작

## 마을
- 드래그: 마을 이동, 마우스 휠: 확대·축소
- 건물·집 탭 → 팝업
- 고양이 탭 → 쓰담쓰담(콩콩 + 하트), 길게 누르기 → 고양이 카드(츄르·씻기기·파티·이동)
- 하단 메뉴: 부화소·상점·짝짓기·도감·모험
- 코인은 집마다 쌓임 → 집 팝업에서 `코인 받기` (집 위 ● 숫자)
- 파티는 최대 3마리, 어느 집에 있든 출전 가능

## 고양이 이동 규칙
- 부화한 고양이는 부화소 앞에서 대기 → 집으로 옮겨야 코인 생산
- 고양이를 끌어서 집 마당에 놓기 → 끄는 동안 받을 수 있는 집은 초록, 안 되는 집은 회색
- 또는 고양이 카드 `이동` → 초록 집 탭
- 팝업이 열려 있는 동안은 마을 드래그·휠이 잠김 (목록 스크롤과 안 겹침)
- 집마다 받는 속성이 정해짐 → 속성이 안 맞으면 이동 불가
- 정원: Lv1 2마리 · Lv2 3마리 · Lv3 4마리 (업그레이드 200·400코인)

| 집 | 받는 속성 | 가격 |
|---|---|---|
| 모닥불 집 | 불꽃 | 시작 지급 |
| 연못 집 | 물방울 | 150 |
| 풀숲 집 | 풀잎 | 150 |
| 바람개비 집 | 바람 | 200 |
| 햇살 정원 | 햇살·달빛 | 300 |
| 숲속 오두막 | 불꽃·풀잎·바람·물방울 | 500 |

## 돌봄 상태
- 배·청결은 시간이 지나면 떨어짐 (배 시간당 12, 청결 시간당 8)
- 배고픔 → 비실비실 느리게 걷고 휘청, 자주 멈춤 / 더러움 → 털이 칙칙해지고 냄새 표시
- 둘 다 좋으면 신나게 걸음 / 배고프거나 더러우면 그 고양이 코인 생산 절반
- 츄르: 배 +40·EXP, 씻기기: 청결 100 (무료) → 고양이 카드에서

## 털 유전자
- 고양이마다 무늬(단색·줄무늬·턱시도·삼색)·털색·몸집 유전자 → 같은 종도 생김새가 다름
- 짝짓기: 부모 유전자 반씩 + 돌연변이 → 새 무늬·색 조합
- 아웃라이어(4%): 콧수염 할배냥·무지개냥·유령냥·왕냥이 → 도감에 기록

## 상점
- 탭: 바구니 / 아이템 / 집, 아이콘 슬롯 격자, 코인 부족하면 구매 버튼 비활성

## 새 버전 알림
- 게임을 켜 둔 채 새 버전이 배포되면 상단에 "새 버전이 나왔어요 [새로고침]" 표시
- 탭이 뒤에 있으면 자동 새로고침

## 부화소·짝짓기
- 부화 슬롯 2개 → 꽉 차면 바구니 구매·짝짓기 불가
- 짝짓기: 고양이 2마리 선택 → 50코인 → 10분 뒤 둘 중 한 종의 바구니

## 고양이 성장
- 츄르: EXP +100, 고급 참치캔: EXP +500
- 레벨업마다 능력치 상승
- Lv10 청소년, Lv20 성묘 → 단계마다 능력치 ×1.3, 몸집도 커짐
- 전투에서 이기면 파티 전원 EXP 획득

## 속성 상성
- 6속성: 불꽃·물방울·풀잎·바람·햇살·달빛
- 불꽃 → 풀잎 → 바람 → 물방울 → 불꽃 (화살표 방향이 강함)
- 햇살 ↔ 달빛 서로 강함
- 유리하면 1.5배 `효과 굉장!`, 불리하면 0.75배 `별로…`

| 고양이 | 속성 | 필살기 |
|---|---|---|
| 치즈 | 불꽃 | 불꽃 냥펀치 |
| 고등어 | 물방울 | 물방울 꾹꾹이 |
| 삼색이 | 풀잎 | 풀잎 할퀴기 |
| 턱시도 | 바람 | 회오리 점프 |
| 크림 | 햇살 | 햇살 하품 |
| 까망이 | 달빛 | 달빛 그림자 |

## 전투
- 화면: 왼쪽 아군 3마리 vs 오른쪽 적, 자동 진행
- 공격 연출: 돌진 → 공격 모션 → 타격 이펙트·히트스톱·화면 흔들림·넉백 → 복귀
- 필살기: 컷인 배너 → 강한 흔들림·필살 이펙트
- 속도 빠른 순서로 차례가 돎
- 고양이는 상성 유리한 적부터, 없으면 체력 낮은 적부터 공격
- 공격하거나 맞으면 필살 게이지 +1, 3칸이 차면 필살기(2.5배)
- 스테이지마다 웨이브 3개: 1웨이브 → 2웨이브 → 3웨이브(보스·강한 적)
- 웨이브 사이 아군 HP·필살 게이지 유지 → 아이템 쓸 타이밍이 중요
- 전체 90턴 안에 못 이기면 패배

## 전투 중 개입
| 조작 | 효과 |
|---|---|
| 적 탭 | 아군 전원이 그 적만 집중 공격 (다시 탭하면 해제) |

| 아이템 버튼 | 즉시 사용, 한 전투 최대 3개 |

| 1-4 빈 공터 | 들쥐 2 → 풀잎 들개 → 들개·들쥐 | 까망이 바구니 |

| 1-6 보스: 쥐 대왕 | 들쥐 2 → 들쥐 3 → 쥐 대왕 | 치즈 바구니 |

- 쥐 대왕: 3턴마다 들쥐를 불러냄 → 부하보다 대왕 집중 공격이 유리
- 불꽃 보스 → 물방울 고양이(고등어)가 유리

## 아이템
| 아이템 | 효과 | 가격 |

| 털실 바구니 | 무작위 속성 고양이 | 100 |

## 공략 팁
- 1-1은 치즈 혼자로 충분 → 고등어를 얻고 파티 2마리로
- 막히면 츄르로 레벨업 → 상점에서 츄르 보충
- 보스 전 캣닢 1개 챙기기 → 대왕에게 필살기 바로 꽂기
- 별 3개는 상성 맞춘 파티 + 집중 공격으로 30턴 안에
