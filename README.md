# 고양이 마을 (YangVil)

털실 바구니에서 태어난 고양이를 키우고, 파티를 꾸려 골목길 모험을 떠나는 육성 수집 RPG.

## ▶ 바로 플레이: https://yangvil.deuklab.workers.dev

- 설치 없이 브라우저(크롬·엣지 권장)에서 바로 실행
- main에 푸시하면 자동 빌드·배포 → 항상 최신 버전
- 플랫폼: PC(Windows) · 웹 브라우저(WebGL)
- 엔진: Unity 6000.4.7f1

## 게임 흐름
- 인트로 → 마을 → 모험(스테이지 선택) → 전투 → 결과 → 마을
- 키운다 → 싸운다 → 보상으로 더 키운다, 이 순환이 기본

## 시작하기
- 인트로에서 `시작하기` → 마을로 이동
- 첫 고양이 `치즈`(불꽃)가 파티에 들어가 있음
- 30초 뒤 부화하는 털실 바구니 1개, 우유 2개, 츄르 3개 지급
- `처음부터`는 저장을 지우고 새로 시작

## 마을
| 탭·버튼 | 하는 일 |
|---|---|
| 고양이 | 보유 고양이 목록, 츄르 주기, 파티 편성·해제 |
| 바구니 | 부화 남은 시간, 다 되면 `부화!`, 기다리기 싫으면 `담요` |
| 상점 | 생선 코인으로 바구니·아이템 구매 |
| 코인 받기 | 고양이들이 모은 생선 코인 수령 |
| 모험 떠나기 | 스테이지 선택 화면으로 이동 |

- 생선 코인은 게임을 꺼둬도 쌓임 (고양이 레벨 합만큼 분당, 최대 300)
- 파티는 최대 3마리

## 고양이 성장
- 츄르: EXP +100, 고급 참치캔: EXP +500
- 레벨업마다 능력치 상승
- Lv10 청소년, Lv20 성묘 → 단계마다 능력치 ×1.3, 몸집도 커짐
- 전투에서 이기면 파티 전원 EXP 획득

## 속성 상성
- 6속성: 불꽃·물방울·풀잎·바람·햇살·달빛
- 불꽃 → 풀잎 → 바람 → 물방울 → 불꽃 (화살표 방향이 강함)
- 햇살 ↔ 달빛 서로 강함
- 유리하면 1.5배 `효과 굉장!`, 불리하면 0.75배 `별로…`

| 고양이 | 속성 | 필살기 |
|---|---|---|
| 치즈 | 불꽃 | 불꽃 냥펀치 |
| 고등어 | 물방울 | 물방울 꾹꾹이 |
| 삼색이 | 풀잎 | 풀잎 할퀴기 |
| 턱시도 | 바람 | 회오리 점프 |
| 크림 | 햇살 | 햇살 하품 |
| 까망이 | 달빛 | 달빛 그림자 |

## 전투
- 자동 진행: 속도 빠른 순서로 차례가 돎
- 고양이는 상성 유리한 적부터, 없으면 체력 낮은 적부터 공격
- 공격하거나 맞으면 필살 게이지 +1, 3칸이 차면 필살기(2.5배)
- 30턴 안에 못 이기면 패배

## 전투 중 개입
| 조작 | 효과 |
|---|---|
| 적 탭 | 아군 전원이 그 적만 집중 공격 (다시 탭하면 해제) |
| 자동필살 OFF + 초상화 탭 | 게이지 찬 고양이의 필살기를 원하는 순간에 예약 |
| 아이템 버튼 | 즉시 사용, 한 전투 최대 3개 |
| 1x / 2x | 전투 속도 |
| 정지 / 계속 | 일시정지 |

## 별점과 보상
- ★ 승리 + ★ 전원 생존 + ★ 10턴 이내 클리어
- 보상: 생선 코인·츄르, 첫 클리어 시 새 속성 바구니
- 스테이지는 이전 스테이지를 깨면 열림

## 스테이지 (1지역 골목길)
| 스테이지 | 적 | 첫 클리어 보상 |
|---|---|---|
| 1-1 골목 입구 | 풀잎 들쥐 | 고등어 바구니 |
| 1-2 쓰레기통 뒤 | 풀잎·불꽃 들쥐 | 턱시도 바구니 |
| 1-3 전깃줄 아래 | 바람 까마귀·물방울 들쥐 | 크림 바구니 |
| 1-4 빈 공터 | 풀잎 들개·불꽃 들쥐 | 까망이 바구니 |
| 1-5 공사장 | 불꽃 들개·달빛 까마귀·풀잎 들쥐 | 삼색이 바구니 |
| 1-6 보스: 쥐 대왕 | 불꽃 쥐 대왕 | 치즈 바구니 |

- 쥐 대왕: 3턴마다 들쥐를 불러냄 → 부하보다 대왕 집중 공격이 유리
- 불꽃 보스 → 물방울 고양이(고등어)가 유리

## 아이템
| 아이템 | 효과 | 가격 |
|---|---|---|
| 우유 한 컵 | 전투: 가장 아픈 아군 HP 30% 회복 | 30 |
| 개다래 잎 | 전투: 쓰러진 아군 HP 50%로 부활 | 80 |
| 캣닢 | 전투: 아군 1마리 필살 게이지 가득 | 40 |
| 츄르 | 육성: EXP +100 | 20 |
| 고급 참치캔 | 육성: EXP +500 | 80 |
| 따뜻한 담요 | 육성: 바구니 즉시 부화 | 50 |
| 털실 바구니 | 무작위 속성 고양이 | 100 |

## 공략 팁
- 1-1은 치즈 혼자로 충분 → 고등어를 얻고 파티 2마리로
- 막히면 츄르로 레벨업 → 상점에서 츄르 보충
- 보스 전 캣닢 1개 챙기기 → 대왕에게 필살기 바로 꽂기
- 별 3개는 상성 맞춘 파티 + 집중 공격으로 10턴 안에

## 저장
- 자동 저장: 변경할 때마다, 앱을 내릴 때
- PC: 사용자 폴더(persistentDataPath)/save.json
- 웹: 브라우저 저장소(IndexedDB) → 같은 브라우저에서 이어하기
