# 냥빌 마을·모험 지도 시각 설계

- 갱신 기준: 마을 배치·공통 시각 규칙·스테이지 지도 변경 시
- 목표: 고양이가 사는 아늑한 마을과 마을 밖으로 이어지는 여정 표현
- 적용: 마을 월드·HUD·스테이지 선택·공통 팝업
- 게임 규칙: docs/game-design.md, 고양이 생활: docs/cat-life-design.md

## 공통 아트 방향

- 따뜻한 크림·살구 지붕·세이지 잔디·하늘색 물·짙은 갈색 글자 사용
- 쿠키런 계열의 풍성한 마을 구도·층진 풍경·명확한 실루엣 참고, 캐릭터·건물은 냥빌 고유 형태
- 지붕·나무·정원·소품의 크기 차이, 발밑 그림자·앞뒤 겹침으로 깊이 표현
- 간판·털실·발바닥·생선·고양이 잠자리로 세계관 통일
- 에셋 미완성 상태도 지붕·벽·문·그림자·식생을 조합해 건물과 지형 구분

## 마을 기본 배치

- 위쪽: 부화소·도감, 중앙: 털실 광장·초기 집, 양옆: 상점·짝짓기 정원
- 아래쪽: 엇갈린 추가 집·연못·산책길, 끝: 모험 게이트
- 첫 화면: 광장·부화소·초기 집과 배회 고양이가 함께 보이는 카메라 구도
- 광장부터 집 입구·모험 게이트까지 굽은 길로 연결, 수목·울타리로 외곽 마감
- 집 6슬롯은 저장 슬롯 의미 유지, 정원·배회·탭 영역을 배치 설정과 함께 이동

## 마을 생활 공간

- 집마다 잠자리·밥그릇·속성 소품, 마당은 잔디 테두리·화단으로 구분
- 광장 랜드마크보다 고양이 생활 공간의 화면 비중 우선
- 나무·지붕의 고양이 가림 제한, 캐릭터·소품 깊이 정렬 적용
- 말풍선·코인 표시는 머리·집 입구와 겹치지 않게 배치
- 집 없는 슬롯은 작은 풀밭·확장 표식, 초회 마을도 광장·식생·소품으로 구성

## HUD·팝업

- 상단: 작은 재화 캡슐, 안내: 접을 수 있는 한 줄 카드, 하단: 아이콘·짧은 이름의 메뉴
- 모험 버튼에 주 강조색, 나머지 기능은 크림 패널·갈색 테두리로 통일
- 팝업: 제목·닫기 고정, 내용만 스크롤, 기존 데이터 바인딩·버튼 이벤트 유지
- 이동 모드: 받을 수 있는 정원 테두리·불가 아이콘·취소 버튼, 색상과 형태 동시 사용
- 장식은 입력 차단 제외, HUD가 가리는 영역은 최초 카메라 구도에서 제외

## 모험 지도 구도

- 진입: 마을 모험 게이트 → 기존 StageSelectScreen 안의 스크롤 지도
- 하단 출발점: 마을 표지판, 중간: 초원·개울 다리·숲길, 상단 종점: 보스 랜드마크
- 기존 1지역 6스테이지를 굽은 길의 6거점으로 연결, 새 지역·전투 규칙 추가 없음
- 지형·길·거점·장식·HUD 순서로 층 구성, 동일한 직사각형 버튼 반복 배치 배제
- 종점이 화면 밖이어도 길·작은 지역 개요로 목적지 방향 표시

## 거점 상태·선택

- 완료: 열린 길·거점 아래 별 0~3개, 현재 도전: 발바닥 표식·밝은 테두리
- 잠김: 닫힌 길·자물쇠·선행 클리어 조건, 보스: 큰 거점·고유 실루엣
- 거점 탭: 하단 상세 카드에 이름·적 정보·보상·기존 파티 확인·출발 기능 연결
- 지도 드래그와 탭 구분, 재진입 시 다음 도전 거점 또는 마지막 선택 위치로 이동
- 산책 보내기·귀가·진행 상태는 지도 위 별도 고정 카드, 거점과 입력 영역 분리

## 로딩·작은 화면

- 배경 로딩: 기본 지형·길·거점 먼저 표시, 로드 실패: 재시도 카드·마을 복귀 제공
- 파티 없음: 출발 카드에서 편성 안내, 잠금 선택: 조건 안내만 표시
- 긴 이름: 최대 두 줄, 거점 간격 유지, 상세 내용만 스크롤
- 좁은 화면: 가로 잘림 없이 지도 폭 조정·세로 스크롤, 출발·닫기 버튼 고정
- Canvas Scaler는 폭 1080 기준, 좁고 긴 화면은 세로 공간 확장

## 카메라 경계

- 최대 확대·축소: 이동 경계 밖 빈 배경 노출 방지, 말풍선·별·선택 표식 가독성 유지

## 구현 경계

- 마을 레이아웃: 건물·집 슬롯·배회 영역·길·카메라 기준을 한 설정에 정의
- 환경 구성: 교체 가능한 건물·정원·장식 프리팹, 씬 월드와 UI 책임 유지
- 지도 거점: 기존 StageData·해금·별점에 바인딩, 레이아웃 정보와 전투 수치 분리
- 생성 콘텐츠는 소스 수정 후 대상만 재생성, 디자이너 수정 프리팹은 별도 갱신 경로 사용
- Addressables 로드·화면 종료 해제, 저장 호환·이벤트 연결 유지

## 승인 후 검증 기준

- 초회·집 6개 마을에서 건물 실루엣·고양이·길·정원이 구별되는 화면 캡처
- 지도 첫 진입·잠김·일부 완료·보스 해금·전체 완료 상태별 화면 캡처
- 540×960·좁은 화면·최대 확대와 축소에서 HUD·말풍선·출발 카드 겹침 점검
- 고양이 쓰담·드래그·집 이동·부화·상점·산책·거점 선택·전투·복귀 유지
- YangVil-check 컴파일 오류 0건·PlaySmokeCheck 결과 오류 0건, 시각 품질은 실제 캡처로 별도 판정
