# 고양이 육성 수집 RPG — 개발 기획·규모·정의서

- 작성일: 2026-11-09
- 엔진: Unity 6 LTS, 2D URP, 모바일 세로 1080×1920
- 레퍼런스: 드래곤빌리지 계열(알 부화·육성·수집·속성 턴제 전투) → 장르만 참고, 이름·캐릭터·아트 차용 금지

## 목표는 한 사이클이 실제로 도는 버티컬 슬라이스다
- 컨셉: 고양이 마을 — 알 대신 "털실 바구니"에서 아기 고양이 부화, 육성·수집·턴제 전투
- 완료 기준: 바구니 획득 → 부화 → 성장 → 전투 → 보상 → 재투자 루프 1회 이상 끊김 없이 완주
- 저장·로드 후 재접속해도 진행 유지

## 코어 루프는 다섯 단계다
- 털실 바구니 획득(상점·스테이지 보상·짝짓기) → 집 배치 → 부화 타이머
- 간식 주기 → 레벨업 → 성장 단계(아기/청소년/성묘) 외형 변화
- 고양이 집에서 생선 코인 자동 생산 → 수령
- 파티 3마리 편성 → 스테이지 턴제 전투
- 전투 보상(코인·간식·바구니) → 다시 육성·확장

## 게임 진행 방식은 자동 턴제 + 개입이다
- 화면 흐름: 마을 → 스테이지 선택 → 파티 확인 → 전투 → 결과(별·보상) → 마을
- 클리어 시 다음 스테이지 해금, 실패 시 입장 비용 없이 재도전
- 행동력·스태미나 없음 → 무제한 반복
- 전투는 자동 진행, 사용자는 원할 때만 개입

## 속성은 여섯 개이고 순환 상성이다
- 속성: 불꽃·물방울·풀잎·바람·햇살·달빛
- 순환: 불꽃 > 풀잎 > 바람 > 물방울 > 불꽃
- 햇살 ↔ 달빛 서로 강함
- 유리 1.5배, 불리 0.75배, 그 외 1배
- 레퍼런스 원작도 6속성 순환 상성 구조(나무위키) → 구조만 참고, 순서·이름은 자체 설계

## 가장 단순한 전투 규칙
- 아군 3 vs 적 1~3, 전원 SPD 내림차순으로 턴, 동률은 아군 우선
- 모든 유닛 자동 행동: 기본 공격, 게이지 차면 필살기 자동 사용
- 자동 대상: 상성 유리한 적 우선 → 없으면 HP 가장 낮은 적
- 적 AI: HP 가장 낮은 아군 공격, 보스는 패턴 순서대로
- 데미지 = ATK × 기술배율 × 상성 − DEF/2, 최소 1
- 스킬 게이지: 공격·피격마다 +1, 3 차면 필살기 → 0 초기화
- 종료: 적 전멸 = 승리, 아군 전멸 또는 30턴 초과 = 패배
- 별점: 승리 1 + 전원 생존 1 + 10턴 이내 1

## 사용자 개입은 네 가지다
- 필살기 수동 발동: 자동 필살 OFF 시 게이지 찬 고양이 초상화 탭 → 원하는 타이밍에 사용
- 대상 지정: 적 탭 → 아군 전원 그 적 집중 공격 (다시 탭하면 해제)
- 아이템 사용: 아이템 버튼 → 대상 탭, 다음 아군 턴 소비 없이 즉시 적용
- 속도·자동 토글: 1x/2x, 자동 필살 ON/OFF, 일시정지
- 개입 없이도 클리어 가능한 난이도 기준, 개입 시 별 3개가 쉬워짐

## 스탯은 네 개만 쓴다
| 스탯 | 용도 |
|---|---|
| HP | 0이면 전투 불능 |
| ATK | 데미지 기준 |
| DEF | 받는 데미지 감소 |
| SPD | 턴 순서 |
- 레벨업마다 종별 성장치만큼 증가, 단계 성장 시 전 스탯 ×1.3

## 아이템 목록 (MVP 8종)
| 아이템 | 종류 | 효과 |
|---|---|---|
| 우유 한 컵 | 전투 소모 | 아군 1 HP 30% 회복 |
| 개다래 잎 | 전투 소모 | 전투 불능 1 HP 50%로 부활 |
| 캣닢 | 전투 소모 | 스킬 게이지 즉시 가득 |
| 츄르 | 육성 | EXP +100 |
| 고급 참치캔 | 육성 | EXP +500 |
| 따뜻한 담요 | 육성 | 부화 남은 시간 즉시 완료 |
| 털실 바구니 | 획득 | 해당 속성 아기 고양이 |
| 생선 코인 | 재화 | 상점 구매·집 확장 |
- 전투 소모템은 한 전투 3개까지, 자동 전투 중 즉시 사용
- 획득처: 스테이지 보상·상점(코인)·도감 보상
- 데이터: ItemData SO (id·이름·아이콘·종류·효과값)

## 적은 베이스 + 배리언트로 만든다
- 배리언트 = 같은 스프라이트·애니 + 속성 색조 + 크기 + 스탯 배율 + 스킬 1개 교체
- 데이터: EnemyBase SO(스프라이트·애니·기본 스탯) + EnemyVariant SO(속성·색조·배율·스킬)
- 디자이너는 베이스 그림만 그림 → 색조·크기는 SpriteRenderer 틴트·스케일로 처리
- 보스 = 베이스 ×1.5 크기 + 패턴 목록 + HP 페이즈

## 잡몹 베이스 3종
| 베이스 | 역할 | 배리언트 예 |
|---|---|---|
| 들쥐 | 약하고 빠름, 떼로 등장 | 불꽃 들쥐·물방울 들쥐… 6속성 |
| 까마귀 | 원거리, 후열 우선 공격 | 바람 까마귀·달빛 까마귀 |
| 들개 | 탱커, 느리고 단단함 | 풀잎 들개·햇살 들개 |
- 베이스당 속성 배리언트 최대 6 → 잡몹 최대 18종

## 보스 종류
| 보스 | 패턴 | 배리언트 |
|---|---|---|
| 쥐 대왕 | 매 3턴 들쥐 소환, 졸개 살아있으면 방어↑ | 속성 6 |
| 까마귀 마녀 | 아군 게이지 깎기, 광역 깃털 | 바람·달빛 |
| 대장 들개 | 2페이즈 HP 50% 이하 분노(ATK↑·SPD↑) | 불꽃·풀잎 |
| 로봇 청소기 | 2턴 차지 후 전체 공격, 차지 중 피격 2배 | 물방울·햇살 |
- MVP: 1-6 보스 = 쥐 대왕(불꽃) 1종
- 나머지 셋은 2지역 이후, 베이스 데이터만 골격에 등록

| 고양이 집 | 3종 |

## 범위 밖
- 결제·광고·서버·PvP·길드·이벤트 → 슬라이스 이후
- 저장 = 로컬 JSON (Application.persistentDataPath)

## 기술 구조
- 데이터: ScriptableObject (CatData·EnemyBase·EnemyVariant·StageData·SkillData·ItemData·BreedTable)
- UI: uGUI + TextMeshPro, 화면당 프리팹 1개, ScreenManager 스택 전환
- 연출: DOTween 트윈, Particle System 이펙트
- 시간: 부화·생산은 UTC 타임스탬프 기준 → 오프라인 진행 반영
- 폴더: Scripts/{Core,Data,Cat,House,Battle,UI} · Art/{Cats,UI,FX} · Data/

## 시스템 정의
| 시스템 | 정의 |
|---|---|
| 부화 | 바구니 → 타이머 종료 → 탭 → 아기 고양이 생성 |
| 성장 | 간식 소모 → EXP → Lv 10/20에 단계 성장 |

| 보상 | 첫 클리어 바구니 확정, 반복은 코인·간식 |
| 도감 | 획득 종 해금, 수집 보상 |
| 저장 | 변경 시·앱 일시정지 시 자동 저장 |

## 수치 기준 (밸런스 초안)
- 첫 부화 30초, 이후 5분~1시간
- 첫 10분: 고양이 2마리·스테이지 3개 클리어 가능
- 1-6 보스: 성묘 1마리 포함 파티로 클리어
- 슬라이스 전체 플레이타임 1~2시간

## 역할 분담
- 프로그래머: 게임 골격 전부 — 데이터·시스템·전투·저장·화면 전환·플레이스홀더 UI
- 디자이너(협업자): UI/UX·고양이 에셋·이펙트 — 골격 위에서 직접 해보며 변경·재구성
- 골격 UI = 동작 확인용 회색 박스, 레이아웃·흐름·연출은 디자이너가 확정
- 디자이너는 Codex + Unity CLI로 프리팹·연출 직접 수정 → docs/collaborator-guide.md

## 에셋 제작 방식
- 고양이: 512×512 PNG 투명, 단계별 idle 4프레임 + 공격 4프레임
- 대안: 파츠 분리 + Unity 2D Animation 본 리깅
- UI: 9-slice 패널·버튼, 아이콘 128×128, 무료 상업용 폰트
- 이펙트: Particle System + 텍스처 시트 → 속성별 타격 6종·성장·부화·레벨업
- 도구: Aseprite/Krita, AI 이미지 생성 시 상업 이용 약관 확인
- 외부 무료 에셋은 출처·라이선스 Credits.md 기록

## UI/UX는 골격 위에서 디자이너가 바꾼다
- 아래 UI 요소는 골격 기준 초안 → 배치·크기·흐름 변경 자유
- 고정: 화면 프리팹이 노출하는 데이터 바인딩 이름(HP·게이지·버튼 이벤트)
- 변경 자유: 레이아웃·색·폰트·애니메이션·화면 전환 연출·버튼 위치
- 화면 추가·삭제·흐름 변경 → 프로그래머와 합의 후 반영

## 전투 화면 UI 요소 (초안)
- 상단 적 + HP바, 하단 아군 3 + HP바·스킬 게이지
- 아군 초상화 = 필살 버튼(게이지 차면 빛남), 아이템 버튼, 턴 순서 바
- 상단 우측: 1x/2x·자동 필살·일시정지 토글, 대상 지정 시 적 위 표식
- 공격 시 돌진 트윈 + 타격 이펙트 + 데미지 숫자 팝업
- 상성 유리 노랑 "효과 굉장", 불리 회색

## 일정 (4주)
- 1주 프로그래머: 골격·데이터·플레이스홀더 전 화면·부화·성장·저장
- 1주 디자이너: 환경 세팅·아트 콘셉트·고양이 1종 3단계·UI 톤 시안
- 2주 프로그래머: 전투·스테이지·아이템·보상 → 전투 루프 완주
- 2주 디자이너: 고양이 6종 1단계·전투 화면 UI 교체·타격 이펙트
- 3주 프로그래머: 생산·짝짓기·도감·상점 → 전체 사이클 연결 (알파)
- 3주 디자이너: 나머지 단계·전 화면 UI/UX 재구성·부화·성장 연출
- 4주 공통: 에셋 교체 마무리·사운드·밸런스·버그·Android 빌드 (베타)

## 완료 판정 체크리스트
- 새 저장으로 시작 → 첫 부화까지 1분 이내
- 오프라인 30분 후 재접속 → 코인·부화 반영
- 1-6 보스 클리어 → 보상 바구니 → 부화 → 편성까지 연결
