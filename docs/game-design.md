# 고양이 육성 수집 RPG — 개발 기획·규모·정의서

- 작성일: 2026-11-09
- 엔진: Unity 6 LTS, 2D URP, 모바일 세로 1080×1920
- 레퍼런스: 드래곤빌리지 계열(알 부화·육성·수집·속성 턴제 전투) → 장르만 참고, 이름·캐릭터·아트 차용 금지

## 목표는 한 사이클이 실제로 도는 버티컬 슬라이스다
- 컨셉: 고양이 마을 — 알 대신 "털실 바구니"에서 아기 고양이 부화, 육성·수집·턴제 전투
- 완료 기준: 바구니 획득 → 부화 → 성장 → 전투 → 보상 → 재투자 루프 1회 이상 끊김 없이 완주
- 저장·로드 후 재접속해도 진행 유지

## 코어 루프는 다섯 단계다
- 털실 바구니 획득(상점·스테이지 보상·짝짓기) → 집 배치 → 부화 타이머
- 간식 주기 → 레벨업 → 성장 단계(아기/청소년/성묘) 외형 변화
- 고양이 집에서 생선 코인 자동 생산 → 수령
- 파티 3마리 편성 → 스테이지 턴제 전투
- 전투 보상(코인·간식·바구니) → 다시 육성·확장

## 게임 진행 방식은 스테이지 턴제다
- 화면 흐름: 마을 → 스테이지 선택 → 파티 확인 → 전투 → 결과(별·보상) → 마을
- 클리어 시 다음 스테이지 해금, 실패 시 입장 비용 없이 재도전
- 행동력·스태미나 없음 → 무제한 반복
- 자동 전투 없음 → 내 턴마다 행동 직접 선택

## 속성은 여섯 개이고 순환 상성이다
- 속성: 불꽃·물방울·풀잎·바람·햇살·달빛
- 순환: 불꽃 > 풀잎 > 바람 > 물방울 > 불꽃
- 햇살 ↔ 달빛 서로 강함
- 유리 1.5배, 불리 0.75배, 그 외 1배
- 레퍼런스 원작도 6속성 순환 상성 구조(나무위키) → 구조만 참고, 순서·이름은 자체 설계

## 가장 단순한 전투 규칙
- 아군 3 vs 적 1~3, 전원 SPD 내림차순으로 턴, 동률은 아군 우선
- 내 차례: 공격 / 스킬 / 아이템 / 방어 중 1개 → 대상 탭
- 적 차례: HP 가장 낮은 아군 기본 공격 (AI 규칙 1줄)
- 데미지 = ATK × 기술배율 × 상성 − DEF/2, 최소 1
- 스킬 게이지: 공격·피격마다 +1, 3 차면 필살기 → 0 초기화
- 방어: 이번 라운드 받는 데미지 절반, 게이지 +1
- 종료: 적 전멸 = 승리, 아군 전멸 또는 30턴 초과 = 패배
- 별점: 승리 1 + 전원 생존 1 + 10턴 이내 1

## 스탯은 네 개만 쓴다
| 스탯 | 용도 |
|---|---|
| HP | 0이면 전투 불능 |
| ATK | 데미지 기준 |
| DEF | 받는 데미지 감소 |
| SPD | 턴 순서 |
- 레벨업마다 종별 성장치만큼 증가, 단계 성장 시 전 스탯 ×1.3

| 우유 한 컵 | 전투 소모 | 아군 1 HP 30% 회복 |

- 전투 소모템은 한 전투 3개까지, 사용 시 턴 1회 소비

## MVP 콘텐츠 범위
| 항목 | 수량 |
|---|---|
| 고양이 | 6종 (속성당 1) |
| 성장 단계 | 종당 3단계 → 스프라이트 18세트 |
| 고양이 집 | 3종 |
| 짝짓기 | 확률표 1개 |
| 스테이지 | 1지역 10스테이지 + 보스 1 |
| 스킬 | 종당 기본 1·필살 1 → 12개 |

## 범위 밖
- 결제·광고·서버·PvP·길드·이벤트 → 슬라이스 이후
- 저장 = 로컬 JSON (Application.persistentDataPath)

## 기술 구조
- 데이터: ScriptableObject (CatData·StageData·SkillData·ItemData·BreedTable)
- UI: uGUI + TextMeshPro, 화면당 프리팹 1개, ScreenManager 스택 전환
- 연출: DOTween 트윈, Particle System 이펙트
- 시간: 부화·생산은 UTC 타임스탬프 기준 → 오프라인 진행 반영
- 폴더: Scripts/{Core,Data,Cat,House,Battle,UI} · Art/{Cats,UI,FX} · Data/

## 시스템 정의
| 시스템 | 정의 |
|---|---|
| 부화 | 바구니 → 타이머 종료 → 탭 → 아기 고양이 생성 |
| 성장 | 간식 소모 → EXP → Lv 10/20에 단계 성장 |
| 생산 | 집 안 고양이 Lv 합 × 분당 코인, 상한 있음 |
| 짝짓기 | 두 마리 선택 → 확률표로 바구니 1개 → 타이머 |
| 전투 | SPD순 턴, 스킬 게이지, 상성 1.5/0.75배 |
| 보상 | 첫 클리어 바구니 확정, 반복은 코인·간식 |
| 도감 | 획득 종 해금, 수집 보상 |
| 저장 | 변경 시·앱 일시정지 시 자동 저장 |

## 수치 기준 (밸런스 초안)
- 첫 부화 30초, 이후 5분~1시간
- 첫 10분: 고양이 2마리·스테이지 3개 클리어 가능
- 1-10 보스: 성묘 1마리 포함 파티로 클리어
- 슬라이스 전체 플레이타임 1~2시간

## 협업자(학생) 에셋 제작 방식
- 학생이 웹서치 + AI 보조로 직접 제작, 프로그래머는 규격만 고정
- 고양이: 512×512 PNG 투명, 단계별 idle 4프레임 + 공격 4프레임
- 대안: 파츠 분리 + Unity 2D Animation 본 리깅
- UI: 9-slice 패널·버튼, 아이콘 128×128, 무료 상업용 폰트
- 이펙트: Particle System + 텍스처 시트 → 속성별 타격 6종·성장·부화·레벨업
- 도구: Aseprite/Krita, AI 이미지 생성 시 상업 이용 약관 확인
- 외부 무료 에셋은 출처·라이선스 Credits.md 기록
