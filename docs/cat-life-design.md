# 냥빌 고양이 생활 기획 — 관계·교감·에피소드·방치 모험

- 작성일: 2026-11-09
- 상위 문서: docs/game-design.md
- 목표: 집에 둔 고양이도 "키우는 맛" → 다마고치식 교감 + 고양이끼리 관계 드라마
- 레퍼런스(구조만): 다마고치(결혼·자녀·방치 반응), RimWorld(호감도·말다툼·싸움), AFK Arena(방치 보상 상한)

## 현재 구현은 전부 일방향이다
- 돌봄 = 배고픔·청결 두 수치, 쓰담 = 하트 연출만
- 배회 = 고양이 각자 무작위 걷기, 서로 무시
- 짝짓기 = 아무 두 마리 선택 → 즉시 바구니, 고양이 의사 없음
- 모험 = 직접 들어가야만 진행

## 고양이마다 성격 하나와 기억이 있다
- 성격 5종: 다정·소심·도도·장난·먹보 → 부화 때 유전자 시드로 결정
- 성격 = 행동 가중치(그루밍·장난·독점·숨기) + 바크 대사 톤
- 유대(사용자↔고양이) 0~100: 쓰담·간식·놀아주기 ↑, 오래 방치 ↓ 완만
- 기억 = 최근 사건 5개(누가·무엇·언제) → 바크·에피소드 재료

## 고양이끼리 호감도가 있고 행동은 쌍방이다
- 호감도 쌍별 −100~+100, 같은 집에서 함께 있으면 서서히 수렴
- 상호작용 = 개시자 성격 × 상대 호감도로 상대 반응 결정 → 받아줌·무시·거절
- 행동표:
  - 서로 그루밍: 호감 +, 둘 다 하트
  - 같이 낮잠(붙어 눕기): 호감 30 이상
  - 쫓기놀이: 장난 성격 개시, 상대가 받아야 성립
  - 하악질: 호감 −20 이하 접근 시
  - 쌈박질: 원인 누적 시 확률 발생(아래)
- 거절도 표시: 개시 → 상대 꼬리 휙·자리 뜸 → 개시자 시무룩 바크

## 싸움은 반드시 이유가 보인다
- 원인 4종(실제 고양이 갈등 요인): 밥그릇 경쟁·잠자리 다툼·영역(집 정원 초과)·질투(사용자가 한쪽만 편애)
- 원인마다 불만 게이지 쌓임 → 하악질 → 임계 넘으면 싸움
- 싸움 직전 바크로 원인 노출: "내 자리였거든!"·"왜 쟤만 쓰다듬어?"
- 싸움 후: 패자 호감 −, 둘 다 청결 −, 화해 그루밍 확률(호감 높으면)
- 관계 카드: 고양이 카드에 친구·앙숙 상위 2마리 + 최근 갈등 원인 한 줄
- 해결 수단: 밥그릇 추가(집 업그레이드)·집 분리·둘 다 쓰담 → 사용자가 원인을 고치는 구조

## 바크 = 머리 위 한 줄 말풍선
- 발화 조건: 상태 변화·상호작용 시작/결과·기억 사건·사용자 접촉
- 대사 = 성격별 표 × 상황 키, 상대 이름 치환
- 빈도 상한: 마리당 20초 1회, 화면 동시 2개
- 모양 = 만화 말풍선(흰 둥근 몸통·진한 테두리·머리 쪽 꼬리), 기분 표시는 말풍선 없이 글자만

## 짝짓기는 둘이 원해야 된다
- 조건: 서로 호감 60 이상 + 둘 다 성묘 + 기분 보통 이상
- 짝짓기 탑 = 후보 쌍 추천 목록(호감 높은 순), 사용자는 "소개"만
- 소개 → 데이트 연출(나란히 걷기·그루밍) → 성공 시 바구니
- 호감 부족 시 거절 바크 + 필요 호감 표시
- 부모 기록 → 아기 카드에 엄마·아빠, 부모는 아기와 기본 호감 +40
- 유전 = 기존 Genetics 유지, 성격은 부모 중 하나 계승 + 낮은 확률 변이

## 에피소드는 조건으로 열리는 짧은 이야기다
- 형식: 3~5컷 말풍선 + 선택지 1개 → 결과(유대·호감·아이템)
- 고양이별 에피소드 3개(성격별 묶음): 유대 30·60·90 도달 시
- 관계 에피소드: 첫 친구·첫 싸움 화해·짝짓기·아기 첫 걸음
- 마을 사건(가벼운 시나리오 축): 비 오는 날 집 잃은 새끼·생선 도둑 까마귀 → 모험 1지역과 연결
- 에피소드 도감 = 수집 요소

## 모험은 방치하면 알아서 돈다
- 방치 모험: 스테이지 선택 맨 위 "산책 보내기" 한 줄 → 최고 클리어 스테이지 반복
- 입장 흐름 = 모험 버튼 → 스테이지 선택, 중간 패널 없음
- 상호작용 연출 = 한 번에 한 쌍, 대답은 앞 말풍선 닫힌 뒤
- 오프라인 진행 = UTC 기준 시뮬 없이 기대값 계산, 상한 8시간
- 효율: 직접 전투 대비 60%, 첫 클리어 보상 제외
- 귀가 시 결과 카드 + 고양이 바크("까마귀 혼내줬어!")와 기억 1건
- 방치 중 고양이는 마을에 없음 → 남은 고양이끼리 관계 변화 발생
- 돌봄 수치가 낮으면 효율 감소 → 육성과 모험 연결

## 방치 처벌은 약하게 둔다
- 굶김·더러움 → 생산·모험 효율만 감소, 사망·가출 없음
- 유대 감소는 하한 20, 복귀 시 반가움 바크로 회복 유도
- 죄책감 유도 대신 "돌아오면 반겨줌" 톤

## 데이터 추가분
- OwnedCat: personality·bond·memories·parentUids
- SaveData: relations(쌍 uid → 호감·불만 원인별)·episodesSeen·expedition(파티·시작 시각)
- 성격·바크·상호작용·에피소드 표 = 코드 표 하나(Core/CatLife) → 정의 한 곳
- 저장 버전 5 → 6, 기존 고양이는 성격 무작위·유대 50·호감 0으로 이행

## 처음 하는 사람에게 가이드가 하나씩 권한다
- 해본 것 기록(tried) → 안 해본 것만 권유, 한 번 해보면 다음으로
- 순서: 부화·이사 → 쓰다듬기 → 길게 눌러 카드 → 츄르 → 이야기 → 싸움 해결법 → 코인 → 파티 → 짝짓기 소개 → 모험 → 산책
- 산책 30분 넘으면 데려오기 권유
- 가이드 버튼 = 해당 고양이로 카메라 이동 + 할 동작 안내

## 구현 순서
- 성격·유대·바크 → 호감도·쌍방 상호작용 → 싸움 원인·관계 카드
- → 짝짓기 조건화 → 방치 모험 → 에피소드
- 각 단계 PlaySmoke 항목 추가
